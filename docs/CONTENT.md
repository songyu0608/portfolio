# CONTENT — 사이트 콘텐츠 체크리스트

단계 4(페이지 구현) 전에 채워야 하는 원고 목록이다. choi가 작성하거나 제공하고, AI는 일본어/영어 문안 다듬기를 돕는다.

- 원고는 한국어로 써도 된다. 사이트 게재용 일본어(기본)·영어 번역은 작업 지시서에서 만든다.
- 이 저장소는 Public이다. 공개해도 되는 정보만 적는다. 전화번호, 집 주소, 현 직장 비공개 정보는 넣지 않는다.
- 실제 콘텐츠 파일은 T01/T03에서 정한 구조(`src/content/`)로 옮긴다. 이 문서는 수집 현황 관리용이다.

## 임시 문구 규칙

2026-10-30 확정. 원고 수집 전에 페이지를 구현할 때(T04~) 적용한다.

- 임시 콘텐츠 항목은 스키마의 `placeholder: true`로 표시하고, 화면 문구에도 표식(일본어 「（仮）」, 영어 `(placeholder)`)을 넣는다.
- 실제 인물·회사·수치로 오해될 문구를 쓰지 않는다. 회사명은 「A社」/`Company A`, 성과 수치와 기간은 「〇〇%」/`XX ms`/`20XX.XX`처럼 기호로 둔다.
- 임시 문구로 구현한 항목은 위 수집 현황 표의 상태를 「미수집(임시 문구로 구현)」으로 적는다.
- 원고를 받으면 콘텐츠 파일의 값을 바꾸고 `placeholder`를 `false`로 바꾼다. 화면 구조는 바꾸지 않는 것이 원칙이다.
- 임시 항목이 남은 채로 배포하지 않는다. 단계 8 배포 전에 빌드 로그의 임시 항목 수가 0인지 확인한다.

## 백엔드 프로젝트 카드 작성 가이드

각 프로젝트는 아래 네 칸을 채운다. 사내 기밀은 일반화해서 쓴다.

- **課題 (문제)**: 어떤 시스템의 어떤 문제였나. 규모(트래픽, 데이터량, 사용자 수)
- **設計 (설계)**: 선택한 구조와 이유, 고려한 대안, 본인의 역할 범위
- **結果 (결과)**: 수치로 표현한 개선 (예: p99 지연 800ms → 120ms, 장애 건수 월 5 → 0)
- **技術 (기술)**: 언어, 프레임워크, DB, 메시지 큐, 클라우드, 관측 도구

## 자격증 표기 규칙

2026-10-28 확정. About 페이지의 자격증 영역에 적용한다.

- **취득한 자격증**: 이름과 취득 연월. 최근 취득 순으로 나열한다.
- **학습 중인 자격증**: 최대 1개. 일본어는 「〇〇 取得に向けて学習中」으로 쓰고, 목록 맨 아래에 둔다.
- 「取得予定（YYYY年MM月）」처럼 예정 날짜를 붙이는 표기는 쓰지 않는다.
- 영어 문구는 페이지 구현 시 확정한다 (안: `Studying for 〇〇`).
- 학습 중이던 자격증을 취득하면 취득 연월을 넣어 취득 목록으로 옮긴다.

표현 방식은 시안 A「シンプルリスト」(claude.ai 디자인 캔버스, 비공개 링크)를 채택했다.

| 열 | 내용 |
| --- | --- |
| 왼쪽 | 취득 연월 `YYYY.MM` (모노스페이스, 보조 텍스트 색). 학습 중 행은 「学習中」(강조색) |
| 오른쪽 | 자격증 이름. 학습 중 행은 「〇〇 取得に向けて学習中」 |

- 시맨틱 마크업은 `<dl>`(연월 = `<dt>`, 이름 = `<dd>`)을 기본안으로 한다.
- 행 사이는 가는 구분선만 두고 카드·아이콘 같은 장식은 넣지 않는다.
- 색·크기 값은 T02 디자인 토큰을 따른다.

## 기술 스택 표기 규칙

2026-10-29 확정. About 페이지의 기술 스택 영역에 적용한다.

- 기술을 분류별로 묶어 나열한다. 분류 안은 주력 기술을 먼저 두고, 나머지는 경험이 많은 순으로 둔다.
- 분류 기본안: 言語 / フレームワーク / データベース / インフラ・クラウド / メッセージング・監視 / CI/CD・ツール. 원고를 받은 뒤 항목이 없는 분류는 빼고, 필요하면 분류를 합치거나 추가한다.
- 숙련도는 막대·별점·%로 표시하지 않는다. 주력 기술(「主軸」)만 구분한다.
- 주력 기술은 분류당 0~2개, 전체 2~4개를 기준으로 한다. Home의 "핵심 기술"(3~6개)에는 주력 기술을 모두 포함한다.
- 섹션 제목은 일본어 「技術スタック」, 영어 `Tech stack`. 분류 이름도 일본어/영어 두 벌을 둔다 (영어 문구는 페이지 구현 시 확정).

표현 방식은 시안 B「分類別タグ」(claude.ai 디자인 캔버스, 비공개 링크)를 채택했다.

| 요소 | 내용 |
| --- | --- |
| 배치 | 분류 블록을 2열 그리드로 배치. 좁은 화면에서는 1열 |
| 분류 제목 | 일본어 이름 + 영어 이름(모노스페이스, 보조 텍스트 색) |
| 기술 | 테두리만 있는 태그. 주력 기술은 강조색으로 채운 태그 |
| 범례 | 섹션 설명 문구로 "채운 태그 = 주력 기술"을 알린다 (색만으로 의미를 전달하지 않기 위함) |

- 시맨틱 마크업은 분류마다 제목(`<h3>`) + 목록(`<ul>`/`<li>`)을 기본안으로 한다. 태그는 링크·버튼이 아니므로 클릭 동작을 넣지 않는다.
- 주력 여부는 색 외에 스크린 리더용 텍스트(예: 시각적으로 숨긴 「主軸」)로도 전달한다.
- 색·크기·모서리 값은 T02 디자인 토큰을 따른다. 채운 태그의 글자 대비는 4.5:1 이상을 확인한다.
