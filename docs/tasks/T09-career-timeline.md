## 목표

About의 경력 타임라인에서, 페이지를 스크롤하면 세로선이 위에서부터 accent 색으로 채워지고 지나간 항목의 점이 강조되게 한다(컨셉 5). **효과가 없어도 지금 화면과 정보가 그대로인 점진적 향상**으로 만들고, About이 받는 JS는 늘리지 않는다.

- `docs/PLAN.md` §5 단계 5. 2026-10-31 사용자 결정으로 T08 = 컨셉 1·2, **T09 = 컨셉 5**, T10 = 컨셉 3·4.
- `AGENTS.md` §7: 핵심 정보는 숨기지 않고, reduced-motion에서 장식 애니메이션을 끄며, 기본 출력 JS를 최소화한다.
- 참고 시안: claude.ai "포트폴리오 인터랙션 컨셉" 캔버스(비공개 링크, 소유자 계정에서만 열림) 5번 보드. 2026-10-28 사용자 확인. 시안 메모 요약:
  - 스크롤하면 선이 채워지고 항목이 차례로 나타남.
  - 스크롤은 누구나 하므로 모든 방문자가 보는 효과.
  - 데모는 박스 안 스크롤, 실제 사이트는 페이지 스크롤.
  - 시안 동작: 지나가지 않은 항목은 불투명도 0.12·아래로 16px, 지나가면 불투명도 1·제자리(450ms). 점은 지나가면 accent 테두리. '동작 줄이기'이면 모두 최종 상태.
  - 시안은 색·글꼴·데이터가 임시다. 색·글꼴·항목 구성은 현재 사이트(T05)를 따르고, 시안에서는 **동작만** 가져온다.
- 현재 코드: `src/components/CareerTimeline.astro`. `<ol class="timeline">` 안의 `.timeline__item`마다 `::before`(다음 점까지의 세로선, border 색)와 `::after`(점, 현재 재직은 accent로 채움)가 있다. 항목은 현재 3개(임시 문구)다. About에서 타임라인 아래에 技術スタック·資格 섹션이 이어진다.

## 범위

포함:

1. **구현 방식 (기본안)**
   - **CSS 스크롤 기반 애니메이션(`animation-timeline: view()`)만 쓰고 JS는 추가하지 않는다.** React island·새 의존성도 쓰지 않는다.
   - 이유: 효과가 "각 항목의 화면 안 위치 → 선·점 스타일" 한 가지라 상태가 필요 없고, 스크롤 이벤트·IntersectionObserver 스크립트 없이 브라우저가 합성 스레드에서 처리할 수 있다. 지원하지 않는 브라우저는 지금 화면(최종 상태) 그대로다.
   - 모든 규칙을 `@supports (animation-timeline: view())`와 `@media (prefers-reduced-motion: no-preference)` 안에 둔다. 둘 중 하나라도 맞지 않으면 T05 화면과 같다.
   - 이 결정을 `docs/DESIGN.md` §3 공통 구현 규칙과 `docs/ARCHITECTURE.md` A2 비고에 반영한다(지시서 PR에서 반영 완료).
   - 대체안: CSS만으로 아래 동작을 만들 수 없거나 지원 브라우저에서 깨지는 문제가 있으면, IntersectionObserver를 쓰는 작은 Astro `<script>`(`src/scripts/career-timeline.ts`, 압축 전 1KB 이하)로 바꿔도 된다. 바꾼 이유를 PR에 적는다.

2. **동작 (기본안)**
   - 선 채움: 각 항목의 세로선(`::before`) 위에 accent 색 2px 선을 겹치고, 그 항목이 화면에 들어와 위로 올라가는 동안 위에서 아래로 0 → 100% 채운다(`transform: scaleY()` 또는 `background-size`, `transform-origin: top`). 기준 구간은 기본안으로 `animation-range: entry 100% cover 50%`(항목이 다 들어온 뒤부터 화면 가운데를 지날 때까지)이며, 실제로 보고 조정해도 된다. 항목마다 따로 채워지므로 이어 보면 선 전체가 위에서부터 채워진다.
   - 점 강조: 항목이 위 구간의 시작에 닿으면 점 테두리가 text-muted에서 accent로 바뀐다. 현재 재직 항목의 채운 점(accent)은 그대로 둔다. 짧은 구간(예: `entry 100%` 부근 10%)으로 바꿔 갑자기 깜박이지 않게 한다.
   - 스크롤을 되돌리면 선·점도 되돌아간다(스크롤 위치에 묶인 상태). 페이지를 맨 위에서 열 때 이미 화면 안에 있는 항목은 그 위치에 맞는 상태로 바로 보인다.
   - **글자는 흐리게 하거나 숨기지 않는다.** 기간·회사명·직무·성과는 언제나 지금과 같은 색·불투명도·위치다. 시안의 "불투명도 0.12에서 나타남"은 적용하지 않는다. 이유: 스크롤을 멈춘 위치에 따라 화면 안 항목 글자가 대비 기준(4.5:1) 아래로 남을 수 있고, 핵심 정보인 경력 문구가 흐리게 보이는 상태를 만들지 않기 위함이다. 사용자가 시안대로의 나타남 효과를 원하면 구현 PR에서 추가한다(메모 참고).
   - 닿지 못하는 항목이 없어야 한다: 페이지 끝까지 스크롤했을 때 마지막 항목 바로 위 선까지 모두 채워지고 모든 점이 강조되어야 한다(타임라인 아래에 기술 스택·자격증 섹션이 있어 지금 구성에서는 닿는다). 1280×800, 1280×1200, 375×667에서 확인한다. 원고 반영 후 아래 섹션이 짧아져도 닿도록 구간을 `cover 50%`보다 늦게 잡지 않는다.

3. **접근성·레이아웃**
   - 새 요소를 넣을 때는 장식이므로 `aria-hidden="true"`이거나 의사 요소로 만든다. 접근성 트리·Tab 순서·HTML 구조(`<ol>`/`<li>`/h3)는 T05와 같다.
   - 레이아웃 이동이 없어야 한다. 크기·위치를 바꾸는 속성(`height`, `top` 등)을 애니메이션하지 않고 `transform`·색만 바꾼다. About의 CLS가 main과 같아야 한다.
   - 대비: 채운 선과 강조 점은 accent / background(라이트 4.74, 다크 8.14)로 §2 기존 조합이다. 선·점은 장식이고 현재 재직 여부는 기간 문구가 전하는 기존 규칙을 유지한다.
   - 인쇄(`@media print`)에서는 효과 없이 최종 상태가 나오는지 확인한다.

4. **문서**
   - `docs/DESIGN.md` §6 경력 타임라인에 스크롤 강조(구간, 색, 조건, 브라우저 지원)를 적고, "단계 5 컨셉 5" 예고 문장을 실제 내용으로 바꾼다. §6 모션도 갱신한다.
   - `docs/ARCHITECTURE.md` §2: 출력 설명의 "페이지가 받는 JS" 문장에 About이 받는 JS가 늘지 않았음을 적는다(대체안을 썼으면 스크립트와 크기).
   - CSS 스크롤 기반 애니메이션의 브라우저 지원 범위(Chromium·Safari·Firefox 버전)를 공식 자료(MDN, caniuse 등)로 확인해 출처와 함께 `docs/DESIGN.md`에 적는다(지시서 작성 시점 확인 필요).

```bash
pnpm install --frozen-lockfile

grep -c "animation-timeline" dist/_astro/*.css   # 규칙이 빌드 CSS에 있는지
```

- `/ja/about/`, `/en/about/`을 천천히 스크롤하며 선 채움·점 강조를 보고, 끝까지 내려 모든 항목이 강조되는지 확인한다. 창 높이를 바꿔 반복한다.

## 메모

- 아래는 지시서 작성 시 정한 기본안이다. 사용자(choi)가 구현 PR에서 바꿀 수 있다: 채움 구간(`entry 100%` ~ `cover 50%`), 점 강조 방식(테두리만 accent), 글자 나타남 효과 미적용.
- 시안대로 "항목이 차례로 나타남"을 넣는다면, 글자를 흐리게 시작하지 않고 `translateY(16px) → 0`만 짧은 구간(`entry 0%` ~ `entry 100%`)으로 주는 방식을 먼저 검토한다. 불투명도를 낮추면 멈춘 위치에서 대비 기준 아래로 남는 경우가 생기므로, 쓰려면 사용자 확인을 받는다.
- 경력 항목은 원고 반영 때 개수·길이가 바뀐다. 항목 수·높이를 가정하지 않는다(항목마다 자기 view timeline을 쓰는 이유).
- CSS 스크롤 기반 애니메이션을 지원하지 않는 브라우저에서는 효과 없이 T05 화면이 정상 동작이다. 폴리필이나 JS 대체 구현은 만들지 않는다(대체안은 CSS로 구현 자체가 안 될 때만).
