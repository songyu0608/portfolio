# REVIEW — AI 교차 리뷰 절차

이 파일은 PR 구현·리뷰 절차의 원본이다. 협업 규칙 전체는 `AGENTS.md` §4를 따른다.

## 기본 원칙

- Claude가 구현한 PR은 ChatGPT(Codex)가 리뷰한다.
- ChatGPT(Codex)가 구현한 PR은 Claude가 리뷰한다.
- 구현과 리뷰는 작업 지시서에 정의된 범위와 완료 조건을 기준으로 한다.
- AI 리뷰와 자동 검사를 함께 사용한다. AI의 승인만으로 merge하지 않는다.
- 최종 merge는 사용자(choi)가 결정한다.

## 진행 순서

### 1. 구현 및 자체 검증

- 구현 AI가 작업 지시서에 따라 코드를 작성한다.
- 해당 단계에서 사용할 수 있는 lint, 포맷 검사, 타입 검사, 빌드, 테스트를 실행한다.
- PR 본문에 변경 내용, 검증 결과, 남은 일을 기록한다.

### 2. PR 교차 리뷰

- 다른 AI가 작업 지시서와 실제 변경 코드를 비교한다.
- 구현 AI의 설명뿐 아니라 코드와 검사 결과를 직접 확인한다.
- 화면 변경이 있으면 가능한 환경에서 실제 화면과 동작도 확인한다.

### 3. 수정 및 재검증

- 구현 AI가 지적 사항을 수정하고 관련 검사를 다시 실행한다.
- 리뷰 AI가 수정 사항과 그로 인한 영향을 재확인한다.
- 최종 검증 결과는 PR의 최신 변경 사항을 기준으로 남긴다.

### 4. 사용자 확인 및 merge

- 필수 검사 통과와 주요 지적 사항 해결 여부를 확인한다.
- 확인하지 못한 항목이나 남은 문제가 있으면 사용자에게 명시한다.
- 사용자가 최종 merge 여부를 결정한다.

## 리뷰 확인 항목

| 항목 | 확인 내용 |
| --- | --- |
| 요구사항 | 지시서의 완료 조건 충족, 누락, 불필요한 범위 확대 |
| 동작 | 정상 흐름, 예외 상황, 기존 기능에 미치는 영향 |
| 구조 | 프로젝트 규칙 준수, 중복, 유지보수에 불필요한 복잡성 |
| 화면·접근성 | 모바일 대응, 키보드 조작, reduced-motion 대응 |
| 다국어 | 일본어·영어 경로, 문구 누락, 하드코딩 여부 |
| 보안 | 비밀 값 노출, 입력 검증, 접근 제어 — 변경 내용에 해당할 때 |
| 검증 | 자동 검사 결과와 실제 실행 확인 여부 |

해당 작업과 관련 없는 항목은 적용 대상이 아님을 표시한다.

## 리뷰 결과 작성 기준

리뷰 결과에는 다음을 구분해서 기록한다.

- **수정 필요**: 발생 조건, 영향, 관련 파일·위치, 판단 근거
- **개선 제안**: 완료 조건을 막지는 않지만 개선할 수 있는 사항
- **확인 완료**: 직접 확인한 코드·동작과 실행한 검사 결과
- **미확인**: 환경이나 정보 부족으로 확인하지 못한 항목과 이유

문제가 발견되지 않았더라도 "문제없음"만 남기지 않고, 확인 범위와 남은 한계를 기록한다. 추측성 지적은 확정된 결함과 구분한다.
